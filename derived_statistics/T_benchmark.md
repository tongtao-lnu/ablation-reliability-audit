## 0. 一句话结论

**三个基准合计 1808 张掩膜，空 GT（= 阴性样本）= 0。**
且该结论在 **三种二值化口径下均成立**（τ>127 / τ>0 / max==0），**对阈值不敏感**。

### 表注（论文可直接引用的事实）

1. **三个基准全部 100 % 阳性** —— 无任何一张"图像内无息肉标注"的样本。
2. **阴性样本 = 0 ⇒ 虚警率（false-alarm rate）在本基准上不可测**，这是**唯一真正的"结构性"缺口**（术语：**虚警盲区**）。
3. 本机**无**任何含阴性样本（健康黏膜）的数据集 → "健康黏膜虚警是否可测"只能写成**限制 + 未来工作**（对应局限 L-③）。

## 2. 空 GT 的阈值敏感性（对应边界条件 **B2**）

检出因子依赖二值化阈值 τ，故"空 GT = 0"这一结论**必须报 τ 并给敏感性**。三种口径实测：

| τ 口径 | 判定含义 | Kvasir-SEG | CVC-ClinicDB | ETIS | **合计** |
|---|---|---|---|---|---|
| **`> 127`**（本项目约定） | 前景 = 亮于中位灰阶 | 0 | 0 | 0 | **0** |
| **`> 0`**（最严：任何非零像素即前景） | 只有在掩膜**恒为 0** 时才算阴性 | 0 | 0 | 0 | **0** |
| **`max == 0`**（最松：整张掩膜恒零） | — | 0 | 0 | 0 | **0** |

**结论**：三种口径下空 GT 均为 0 → **"基准 100 % 阳性"对 τ 稳健，不因阈值选择而翻转**。

### 但 τ 在**像素级**确实有影响（如实报告）

| 基准 | 落在开区间 `0 < v < 255` 的像素 | 占该基准总像素 |
|---|---|---|
| Kvasir-SEG | **2 575 997** | **0.7317 %** |
| CVC-ClinicDB | 91 043 | 0.1345 % |
| ETIS-LaribPolypDB | **0** | **0 %** |

- 把 τ 从 127 降到 0，Kvasir 会多出 1 312 515 个前景像素（+0.3728 %），CVC 多出 91 011 个（+0.1345 %）。
- **即：τ 改变前景的"边界厚度"，但不足以让任何一张掩膜变空** → 样本级结论不动，像素级结论需报 τ。

## 4. 掩膜存储格式审计（本段新增发现）

| 基准 | 格式 | 有损? | 严格二值? | 后果 |
|---|---|---|---|---|
| Kvasir-SEG | **JPEG** | ✅ **有损** | ❌ **0 / 1000** | 掩膜**不是真二值**；每张掩膜仅 16–18 个不同灰度值，边界处有压缩伪影 |
| CVC-ClinicDB | TIFF | ❌ 无损 | 部分（474 / 612） | 少数掩膜含 `1..127` 的低灰阶像素（疑为边界抗锯齿或次级标注） |
| ETIS-LaribPolypDB | PNG | ❌ 无损 | ✅ **100 %** | 唯一完全干净的基准 |

> **Kvasir-SEG 掩膜以 RGB JPEG 存储**：已逐像素核验 **R = G = B**，
> 故按灰度读取与取单通道**结果完全一致**，不存在通道串扰。
> 但 **JPEG 有损压缩**使"二值掩膜"成为**近似**：把 τ 从 127 降到 0 会多收 0.37 % 的像素。
> → 论文报告检出/勾画分解时，**必须写明 τ = 127 并声明掩膜经 JPEG 有损存储**（B2 义务）。
> → 反向印证：**域外基准 ETIS 反而是唯一 100 % 严格二值的**（域内基准更"脏"）。

## 5. 小型病灶过滤审计（实证：过滤是 **no-op**）

`preprocess_data.py` 末端有一行硬编码过滤：

```python
if mask.sum() < 100:      # 前景像素 < 100 的样本被静默丢弃
    continue
```

复刻其语义（resize 到 **352×352** + `INTER_NEAREST` + τ>127）实测：

| 基准 | 过滤阈值 | 352² 下**最小**前景像素 | 低于阈值的张数 | 是否被过滤 |
|---|---|---|---|---|
| Kvasir-SEG | 100 px | **591** | **0** | ❌ 未丢任何样本 |
| CVC-ClinicDB | 100 px | **414** | **0** | ❌ 未丢任何样本 |
| ETIS-LaribPolypDB | 100 px | **133** | **0** | ❌ 未丢任何样本 |

- **佐证**：`processed_data` 三个 split 合计 1128 + 242 + 242 = **1612**，**等于输入总数 1612** → 确实一张未丢。
- **含义**：该过滤**没有**改变基准构成，故**不构成额外的选择偏倚**；
  但它说明基准中**最小的病灶在 352² 下仍有 414–591 px 前景**，
  即基准**不含"极小病灶"这一最难检出情形**——这是与"检出饱和"相关的背景事实，**不是**新的选择效应。
